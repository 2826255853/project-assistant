## 实现范围

- `settings_get/settings_update` 使用正式 IPC v1、固定错误、服务端关联 ID 和白名单命令日志。仅本地 main 获得权限；overlay、未授权窗口及远端页面不能直接读写完整设置。
- 默认值：Bing、最近使用、审批 ask、日志 info、摘要期限 30 天（整数 1–365）；editor/AI 默认值保持 null。摘要采集保持关闭，期限设置不会开启采集；日志级别仅保存配置，日志落盘/清理仍属步骤 1.5。
- 编辑器 DTO 为 `{id:"custom", executable:"绝对 .exe 路径"}`，空值用于清除；不接受命令参数、相对路径、上级路径或自由配置对象。AI 默认配置非空写入暂拒绝，等待 profile/凭据/能力服务，不绕过后续安全门。
- 常驻 DTO 包括 `overlay_enabled`（首次 true）、`overlay_shortcut`（Ctrl+Alt+Space）及 `overlay_position`（x/y、monitor、scaleFactor）。展开/收起与草稿不入数据库；停用状态重启保持停用，启用状态重启只显示悬浮球。
- 新增不可变迁移 `0002_settings.sql`，schema v2 增加全局修订行及类型化 resident_preferences；原 `0001_initial.sql` 与校验和不变，升级前保留 SQLite 一致性备份。初始化缺失项用默认值，存在的非法值报 PA_SETTINGS_CORRUPT，不静默覆盖。
- 第一次 SQLite 初始化常驻设置时，只导入本应用旧 `overlay-settings.json` 的启停、快捷键和位置。旧文件保留、不再写入；导入提交后不再读取，防止旧停用值被重复覆盖。格式损坏或读取失败报错且保持原数据，暂停常驻入口并保留主窗口/退出入口。
- `expectedRevision` 是全局设置批次修订号，不是单键修订。Immediate 事务内核验、写入整批值、更新修订；非法值、重复键、修订冲突、SQL 故障和快捷键注册失败拒绝整批。窗口/快捷键先应用再提交，失败恢复旧运行状态；恢复自身失败返回 PA_SETTINGS_RECOVERY_FAILED，不宣称成功。读取也在事务快照内完成。
- 设置表单区分读取、编辑、保存中、成功及失败；成功使用服务返回值刷新。干净表单跟随托盘事件重读；编辑中保留草稿与原修订，发生冲突后禁用提交，用户先显式重读再重新编辑，不自动覆盖。
- 设置页、托盘菜单回调、窗口关闭、快捷键修改和拖动位置均通过同一设置服务持久化，提交后发送既有无载荷状态失效事件。位置按当前工作区校正、缩放比例调整；缺失显示器回退主显示器可见位置。移动回调只提交当前位置，避免覆盖其他设置；无变化不递增修订。
- 项目范围在阶段 2 尚无授权入口，当前一律拒绝，不能以客户端传入 projectId 或仅存在数据库记录取得权限。cc-switch 和共享 Codex 配置不被访问；没有真实 Key、官方请求或模型用量。

## 可重复验证

```powershell
npm run verify:settings
npm run verify:state
npm run verify:storage
cargo fmt --check --manifest-path src-tauri/Cargo.toml
```

`verify:settings` 构建前端、执行 Rust/IPC 测试及 cargo check，再分别在 dev/built 资源模式启动三个独立桌面进程：保存并停用 → 退出重启读回并启用展开 → 再退出重启确认收起。每组使用独立临时业务数据库，不接触用户数据库、外部配置或凭据。调试夹具只在 debug 构建且 PA_IPC_VERIFY=1 时获 main 授权；发布构建不存在该夹具。

主要证据：`artifacts/phase-1-4/report.json`；桌面截图与日志：`artifacts/shell-{dev|built}-settings-{write|read|enabled}/`。产物不入版本管理。
