cc-switch 保存的默认模型与 Codex 实时模型有差异，报告中 `modelMatches=false`，其余连接匹配通过。这表示当前模型选择发生变化，不表示站点或认证来源失配。测试按实时选择读取能力并完成真实推理；未覆写任何共享默认值。

可重复补测入口：

```powershell
npm run test:codex
npm run verify:phase-0:cc-switch
```

补测入口只读核对当前选项，然后串行执行安装调查、真实非官方链路和隔离站点实验。一次性 SQLite 诊断只在内存核对选中记录，不作为应用运行时接口、不写内部表、不复制数据库或配置、不输出 Key/完整回复/远端错误。真实脚本启动前拒绝官方源及无法确认的配置。
