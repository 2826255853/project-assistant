## 0.7 风险定稿与阶段门归类

用户已确认手动 cc-switch / 应用自管 profile，R-013 按范围调整关闭，R-014 转为自管功能上线门；阶段 0 方案验证完成，阶段门按替代范围通过，允许启动阶段一。不得把范围调整当成自动接口实测通过，也不得用独立 home 推断共享代理安全。

R-005、R-016、R-019、R-020 属于相应功能开放前必须关闭的风险：它们不要求在无凭据、无文件打开、无网络搜索、无持久审批功能的基础壳层中全部先行实现，但功能不得越过各自验收门。R-003、R-015、R-018 限制系统/模型/协议兼容承诺，版本或范围变化时复审。负责人仍为表内职责角色，未指定具体人员。

当前阶段门与首批任务见 [0.7 复审](phase-gate-review.md)，边界与验收见 [ADR-0011](self-managed-profile-adr.md)。
