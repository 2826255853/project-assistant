# ADR-0011：用户手动管理 cc-switch，应用自管 profile

日期：2026-10-11（Asia/Shanghai）。状态：采用。依据：用户明确要求改为“用户手动管理 cc-switch、应用自管 profile”。本 ADR 替代 ADR-0006 的 cc-switch 自动接入范围和 ADR-0010 的阶段一阻塞结论；历史实验与原当时判断保持不变。

## 决策与职责

| 对象 | 管理者与当前范围 |
| --- | --- |
| cc-switch 与用户共享 Codex 配置 | 用户在应用外自行操作。本应用不自动读取、导入、同步、编辑或切换 profile/Key，不调用内部表、Tauri 命令、深链或社区 CLI，不要求安装/版本检测，不管理外部进程。 |
| 应用 profile | 用户在设置页手动填写名称、HTTPS endpoint、Responses 协议、默认模型/强度。Rust 服务管理启停、修订、默认值、连接测试和删除约束；无默认配置时提示创建，不自动从外部取值。 |
| 应用 Key | 用户单独提交至 Rust 系统凭据服务；按 profile ID、origin、credential revision 绑定。普通库仅逻辑引用，IPC 返回仅状态/版本，无 Key 读取或批量导出。凭据库不可用时拒绝操作，不落明文。 |
| 模型能力与任务快照 | Codex 网关按所选 profile 获取目录并验证组合；目录声明不代表远端可用。每个任务固定实际 endpoint、模型、强度、修订和凭据引用；后续配置变更不修改既有快照。 |

官方源、官方认证和官方/中转站切换仍仅预留，不实测、不纳入通过判定，不记为实测通过。

## 运行与切换边界

1. 自有 app-server 使用应用专属、按进程/配置修订隔离的 CODEX_HOME，配置由应用元数据与所选凭据生成。配置中不含外部 MCP、插件、通知钩子或用户信任设置。凭据优先通过经验证的进程专属通道传入；若 CLI 必须使用认证文件，文件只在受限临时 home 存活，按当前用户 ACL 保护，退出/失败及下次启动清理，不进备份/诊断。
2. 启动环境采用明确允许列表，处理继承的认证/provider/代理覆盖；服务层核验项目级配置不能覆盖所选 endpoint/协议/凭据。未知覆盖或无法核验时拒绝启动。
3. 本路线不支持依赖 cc-switch 共享可变代理或接管路由的 profile。仅独立 home 不能保证实际网络路由独立；检测到共享代理、路由漂移或隔离无法核验时返回 `PA_PROVIDER_SHARED_ROUTE_UNSAFE`，失效 ready 状态并阻止新任务。不得通过读取 cc-switch 内部数据来实现检测。
4. 默认串行复用自有进程。默认 profile 切换作用于未来任务；需要改动进程配置时排队等待受影响自有任务空闲，重建自有进程/会话。多 profile 并行另行验证。profile/Key 修改、替换或移除不得改变运行中任务的凭据/路由，必要时等待空闲。
5. 候选使用独立自有进程测试，绑定完整 selection/revision，失败不提交。锁内重新验证后应用配置、校验生效值、原子提交默认值；区分 unchanged、rolled_back 和 rollback_failed。恢复失败时 active=null，阻止新任务；只恢复应用自己的配置。
6. 用户在应用外手动切换 cc-switch 不触发同步或配置监控。本应用不改用户共享 config/auth，不停止外部任务。验收使用隔离外部配置夹具，不为了证明共存而改动用户实际共享配置。

## 需求与验收变更

FR-AI-006 改为手动管理边界与自管配置隔离；FR-AI-001–005/007/008 继续按应用自管语义实现。AT-AI-005 验证运行中默认切换、自有进程等待和外部手动配置隔离；AT-AI-006 验证应用重启及失效处理，cc-switch 未安装/升级不构成依赖；新增 AT-AI-008 验证外部配置不读写、环境/项目覆盖拒绝和实际请求来源。

schema v1 和迁移校验和不修改。阶段一服务仅接受 `adapter_kind=self_managed`、`external_profile_id=NULL`、`routing_scope=owned_process`；v1 的 cc_switch/shared_global 枚举仅为历史/预留，不能激活。遇到不支持的旧记录标记不可用并提示用户手动重建，不自动迁移或解析外部凭据。

## 阶段门与剩余验收

步骤 0.3 在替代范围内通过：已存在真实非官方源通信、两个模型/强度组合、取消/命令审批及独立 home 合成站点的切换/Key 绑定/失败保留证据。步骤 0.7 据用户确认的替代方案重新评审，阶段 0 按替代范围通过，允许启动阶段一。此阶段门结论不替代生产功能验收。

R-013 因取消自动接入要求而退出当前范围，**不是接口已验证**。R-014 保留为自管生产路由隔离功能门：专属 home、环境清理、项目配置覆盖拒绝、外部配置共存、实际路由及运行中任务不可漂移须实测。R-016 系统凭据库、R-005 未覆盖审批/持久恢复、R-019 路径/HTTPS 权限、R-020 日志/原子审批按各自功能上线门执行。

当前没有新增真实服务、cc-switch 接口或共享代理实验；没有实现正式 profile/凭据/任务服务。旧报告的 blocked 保留其原范围含义，不能改成 passed。阶段一实现后按 AT-AI-001/003–008 和安全清单重新生成对应证据，凭据服务及生产隔离通过前不开放真实 Key/任务功能。
